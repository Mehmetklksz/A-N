# A-N — Tasarımcı Portföyü Arayüzü

HTML ve CSS kullanılarak hazırlanmış, tasarımcı portföyü temalı bir arayüz çalışması. Görünüm, referans bir tasarımdan ilham alınarak pratik amacıyla yeniden oluşturulmuştur.

> Sayfadaki isim, deneyim ve ödül bilgileri örnek içeriktir; gerçek kişi veya deneyimi temsil etmez.

## Teknolojiler

- HTML
- CSS

## Durum

Bu proje bir arayüz çalışmasıdır. Bağlantıların ve etkileşimlerin tamamı işlevsel olmayabilir.
